Chasse au Trésor Numérique

Bienvenue à la Chasse au Trésor numérique proposée par l'équipe de la TAG con 2025 !

Le but de cette chasse est de résoudre 6 énigmes. Chaque énigme vous donnera un code. Une fois que vous aurez récupéré tous les codes, vous devrez entrer le "mot" dans le formulaire pour recevoir votre récompense !

Bonne chance et que la chasse commence !

Règlement de la Chasse au Trésor Numérique - TAG Con 2025

  1. But de la Chasse au Trésor :

    Résolvez 6 énigmes pour découvrir des codes. Chaque code mène au suivant. Le dernier code doit être soumis dans le formulaire pour obtenir la récompense.

    Note : Nous encourageons un esprit de compétition sans recourir à l’intelligence artificielle ou à des outils automatisés.

  2. Modalités de Participation :

    Aucune inscription préalable nécessaire. Suivez les liens pour accéder aux énigmes.

    Les énigmes commencent le samedi 26 avril 2025 à 16h et se terminent à 21h le même jour. Le gagnant sera annoncé à 21h.

    Soumettez le code final dans le formulaire avant 21h, dans un délai de 6 heures maximum.

  3. Règles de Participation :

    Résolvez les 6 énigmes pour obtenir un code à chaque fois. Le dernier code, qui sera la réponse finale, doit être soumis dans le formulaire en ligne.

    Pas de tricherie. L'utilisation d’outils externes ou d’IA entraînera une disqualification.

  4. Récompenses :

    Le gagnant recevra une récompense spéciale annoncée à la fin de la chasse.

  5. Soumission du Code Final :

    Le code final doit être soumis avant 21h le samedi 26 avril 2025, dans le formulaire en ligne accessible via le lien fourni.

  6. Aides et Assistance :

    Si vous avez besoin d'aide pour les énigmes, contactez-nous via WhatsApp aux numéros suivants :

    • Pour toute autre assistance (problèmes techniques, soumission du code, questions diverses) :
      • 1. +257 71 51 60 13

    Les demandes d'aide via WhatsApp sont limitées à deux par participant.

  7. Contact en Cas de Problème :

    Si vous avez un problème avec le formulaire, contactez-nous via WhatsApp, mais ce dernier est réservé aux problèmes majeurs.

  8. Disqualification :

    Les tentatives de tricherie entraîneront une disqualification immédiate.

Nous vous souhaitons bonne chance et espérons que vous apprécierez cette chasse au trésor numérique !
