Chasse au Trésor Numérique

Bienvenue à la Chasse au Trésor numérique proposée par l'équipe de la TAG con 2025 !

Le but de cette chasse est de résoudre 6 énigmes. Chaque énigme vous donnera un code. Une fois que vous aurez récupéré tous les codes, vous devrez entrer le dernier code dans le formulaire pour recevoir votre récompense !

Bonne chance et que la chasse commence !

Règlement de la Chasse au Trésor Numérique - TAG Con 2025

  1. But de la Chasse au Trésor :

    Le but de cette chasse au trésor est de s'amuser en résolvant 6 énigmes. Chaque énigme donnera un code. Une fois que vous aurez trouvé tous les codes, vous devrez soumettre le dernier code dans le formulaire pour recevoir votre récompense.

    Remarque importante : Nous encourageons l'esprit de compétition tout en évitant l'utilisation d'outils automatisés ou d'intelligence artificielle pour résoudre les énigmes. La chasse est avant tout un défi de réflexion !

  2. Modalités de Participation :

    Pas d'inscription préalable nécessaire. Il suffit de suivre les liens internet pour accéder aux énigmes.

    Les participants doivent résoudre les 6 énigmes, chacune donnant un code à entrer dans le formulaire en ligne.

    La chasse commence le samedi 26 avril 2025 à 16h et se termine le même jour à 21h. Les gagnants seront annoncés à 21h.

    Les participants doivent soumettre le code final avant 21h, dans un délai de 6 heures maximum.

  3. Règles de Participation :

    Chaque participant devra résoudre 6 énigmes. Chaque énigme donnera un code.

    Le dernier code sera un code numérique que les participants devront soumettre via le formulaire en ligne.

    Pas de tricherie. L’utilisation de l’intelligence artificielle, de moteurs de recherche ou d'autres moyens externes pour résoudre les énigmes entraînera la disqualification.

    Le participant qui soumettra correctement le code final et dans les temps sera le gagnant.

  4. Récompenses :

    Le gagnant recevra une récompense spéciale, qui sera annoncée à la fin de la chasse.

  5. Soumission du Code Final :

    Le code final doit être soumis dans les 6 heures imparties, c’est-à-dire avant 21h le samedi 26 avril 2025.

    Pour soumettre le code final, il vous suffit de le taper dans le formulaire en ligne accessible via le lien fourni.

  6. Aides et Assistance :

    En cas de difficulté avec les énigmes, chaque participant a droit à deux aides :

    • Par email : Si vous rencontrez un problème, vous pouvez nous contacter via l'email fourni dans le règlement.
    • Via WhatsApp : En cas de besoin, vous pouvez aussi nous contacter directement par WhatsApp. L'usage de WhatsApp est permis, mais uniquement en cas de problème majeur avec les énigmes ou la soumission du code.

    Important : Chaque participant n'a droit qu'à deux demandes d’aide pendant la chasse.

  7. Contact en Cas de Problème :

    Si vous avez un problème avec le formulaire, vous pouvez nous contacter directement par email ou par WhatsApp. Le WhatsApp doit être utilisé en dernier recours, après avoir tenté de soumettre votre code via le formulaire.

    L'assistance via WhatsApp est disponible pour vous aider, mais n'est pas destinée à donner des réponses directes aux énigmes.

  8. Disqualification :

    Toute tentative de tricherie (utilisation d'outils externes, tricherie lors des énigmes, etc.) entraînera une disqualification immédiate.

    Le non-respect des règles de participation et de soumission du code final dans les délais entraînera également la disqualification.

Énigme 1 : Le départ de l'aventure

Pour commencer, voici votre première énigme :

Quel est l'animal qui fait le plus de bruit mais qui ne possède pas de voix ?

Réfléchissez bien, la réponse vous amènera au prochain indice !

Voici votre deuxième énigme :

Je suis souvent vu dans les forêts, mais je ne suis pas un arbre. On me trouve souvent sous forme de champignon. Qui suis-je ?

Voici l'énigme numéro 3 :

Énigme 4 : Le voyage dans le temps

Voici l'énigme 4 :

Si tu me coupes, tu me perds. Si tu me portes, tu me gâches. Qui suis-je ?

Énigme 5 : À la recherche du trésor

Voici l'énigme numéro 5 :

Dernière énigme avant de soumettre votre code :

Je suis toujours devant toi, mais tu ne peux jamais me rattraper. Qui suis-je ?
